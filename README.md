# ⚡ ShiftConvert — Мгновенный радиальный конвертер файлов для Windows

**ShiftConvert** — это автономное, сверхбыстрое десктопное приложение для Windows 10 и Windows 11 на C# (.NET 8 + WPF), которое позволяет конвертировать видео, изображения, документы и архивы прямо в момент перетаскивания файла в Проводнике или на Рабочем столе.

Потяните любой файл мышкой и нажмите клавишу **`Shift`** — вокруг курсора мгновенно раскроется радиальное колесо доступных форматов. Отпустите файл на нужном секторе, и готовый результат появится в той же папке (и опционально скопируется в буфер обмена под `Ctrl + V`).

## ✨ Возможности

### 🎬 Видео (Аппаратное ускорение Windows Media / WinRT)
- **Извлечь звук (`MP3`)** — мгновенное извлечение аудиодорожки из любого видео (`MP4`, `MOV`, `MKV`, `WEBM`, `AVI`).
- **Адаптивное сжатие (`Сжать 720p`)** — умный расчёт целевого битрейта (`~42%` от исходного) и жёсткий контроль размера: сжатый видеофайл **гарантированно весит меньше оригинала**.
- **Универсальный `MP4` (H.264)** — перекодирование `MOV / MKV / WEBM / AVI` в совместимый `MP4` без раздутия файла.
- **Склейка нескольких видео (`MP4`)** — выделите 2 или более видеофайлов, перетащите с `Shift` и объедините их в один ролик.
- **Анимированный `GIF`** — создание зацикленной GIF-анимации из видеофрагмента.
- **Без звука (`Mute`)** — быстрое удаление микрофона/аудиодорожки из видео с сохранением качества.
- **Кадр `PNG`** — извлечение чёткого кадра-обложки из видео.

### 🖼 Изображения и Документы
- **Конвертация в 1 клик**: `PNG`, `JPG`, `WEBP`, `ICO` (мультиразмерная иконка), `BMP`, `GIF`.
- **Адаптивное сжатие фото (`Сжать`)** — ступенчатый подбор качества JPEG и разрешения, гарантирующий уменьшение веса даже для уже сжатых снимков.
- **Многостраничный `PDF`** — конвертация одного изображения в документ или склейка нескольких картинок в единый PDF.
- **Локальный `OCR`** — мгновенное распознавание текста с картинок и скриншотов через встроенный движок Windows OCR сразу в буфер обмена.
- **Инструменты**: обрезка `1:1 Квадрат` (для аватарок), `Ч/Б` (монохром), генерация `Base64 Data-URI` и `CSV ↔ JSON / HTML`.

### 📦 Архивы и Контроль процесса
- **Потоковая упаковка и распаковка `ZIP`** с живым индикатором прогресса (`1% → 99%`).
- **Отмена конвертации (`✕ Отменить`)** — возможность в любой момент прервать обработку тяжёлого видео или большого архива с автоматическим удалением недописанных временных файлов.
- **Компактная история (5 последних операций)** — быстрый переход к файлу в Проводнике (`📂`), удаление записи из списка (`✕`) или удаление самого сконвертированного файла с диска (`🗑`).
- **Гибкие настройки и 2 режима работы**:
  - **Глубокий спящий режим (`Shift` на лету)**: при закрытии окна (`✕`) интерфейс полностью выгружается из оперативной памяти (`0% CPU`, `~3 МБ ОЗУ`), оставляя только микро-слушатель клавиши `Shift` и иконку в системном трее.
  - **Контекстное меню Проводника (`ПКМ → ⚡ ShiftConvert`)**: работает **даже при полностью выключенном приложении** (`0 МБ в фоне`). Достаточно нажать правой кнопкой мыши по любому файлу или папке, выбрать формат на появившемся под курсором колесе — программа выполнит конвертацию и сама закроется.
  - Включение/отключение автокопирования результата в буфер обмена (`Ctrl + V`), уведомлений и автозапуска с Windows.
